# 内测安装包授权系统设计文档

## 一、整体流程

```
内测安装包启动
      ↓
读取本地设备码 client_id
      ↓
查询云端该设备码是否已绑定QQ号？
      ↓                          ↓
    未绑定                      已绑定
      ↓                          ↓
弹出QQ号输入窗口            直接进入主程序
      ↓
提交 QQ号 + client_id 到云端验证
      ↓
┌─ QQ号在授权列表？─ 否 → 提示无权限
├─ QQ号未绑定其他设备？─ 是 → 提示该QQ号已绑定其他设备
├─ 防爆破冷却检查？─ 触发 → 提示冷却中，请X分钟后重试
└─ 全部通过 → 绑定 client_id ← QQ号，返回成功
      ↓
进入主程序
```

## 二、数据库表设计

### 2.1 `beta_qq_auth` — QQ号授权名单

```sql
CREATE TABLE IF NOT EXISTS beta_qq_auth (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    qq_number VARCHAR(20) NOT NULL UNIQUE,   -- 授权的QQ号
    remark VARCHAR(100) DEFAULT "",          -- 备注（如：测试员A）
    is_active BOOLEAN DEFAULT 1,             -- 是否启用
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

### 2.2 `beta_device_bind` — 设备绑定记录

```sql
CREATE TABLE IF NOT EXISTS beta_device_bind (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    qq_number VARCHAR(20) NOT NULL,           -- 绑定的QQ号
    client_id VARCHAR(64) NOT NULL UNIQUE,    -- 设备码（一台设备一个）
    platform VARCHAR(10) DEFAULT "",          -- 平台
    version VARCHAR(20) DEFAULT "",           -- 绑定时的客户端版本
    bind_ip VARCHAR(45) DEFAULT "",           -- 绑定时的IP
    bound_at DATETIME DEFAULT CURRENT_TIMESTAMP,  -- 绑定时间
    last_active DATETIME DEFAULT CURRENT_TIMESTAMP, -- 最后活跃
    UNIQUE(qq_number)                          -- 一个QQ号只能绑一台设备
);
```

> 关键约束：`beta_device_bind` 表上 `qq_number` 加 `UNIQUE`（一个QQ只能绑一台设备），`client_id` 也加 `UNIQUE`（一个设备只能绑一个QQ）。

### 2.3 `beta_auth_log` — 验证日志（用于防爆破）

```sql
CREATE TABLE IF NOT EXISTS beta_auth_log (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    client_id VARCHAR(64) DEFAULT "",
    qq_number VARCHAR(20) DEFAULT "",
    ip VARCHAR(45) DEFAULT "",
    success BOOLEAN DEFAULT 0,
    fail_reason VARCHAR(50) DEFAULT "",
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

## 三、防爆破机制

### 3.1 冷却策略

| 条件 | 冷却时间 |
|------|----------|
| 同一 client_id / IP 连续失败 3 次以内 | 无冷却 |
| 失败 4~6 次 | 冷却 5 分钟 |
| 失败 7~10 次 | 冷却 30 分钟 |
| 失败超过 10 次 | 冷却 24 小时 |

### 3.2 实现逻辑（云端）

```php
// 查询最近1小时内该 client_id 或 IP 的失败次数
$failCount = $pdo->prepare("
    SELECT COUNT(*) FROM beta_auth_log
    WHERE (client_id = ? OR ip = ?)
      AND success = 0
      AND created_at > datetime('now', '-1 hour')
");
$failCount->execute([$clientId, $ip]);
$count = (int)$failCount->fetchColumn();

// 计算冷却剩余时间
$cooldownSeconds = 0;
if ($count >= 10) $cooldownSeconds = 86400;      // 24h
else if ($count >= 7) $cooldownSeconds = 1800;   // 30min
else if ($count >= 4) $cooldownSeconds = 300;    // 5min

if ($cooldownSeconds > 0) {
    // 查最近一次失败时间，计算剩余冷却
    $lastFail = $pdo->prepare("
        SELECT created_at FROM beta_auth_log
        WHERE (client_id = ? OR ip = ?) AND success = 0
        ORDER BY created_at DESC LIMIT 1
    ");
    $lastFail->execute([$clientId, $ip]);
    $lastTime = strtotime($lastFail->fetchColumn());
    $remaining = $cooldownSeconds - (time() - $lastTime);
    if ($remaining > 0) {
        // 返回冷却中
        respondError("操作过于频繁，请 " . ceil($remaining / 60) . " 分钟后重试");
    }
}
```

## 四、云端 API 设计

### 4.1 接口清单

| 接口 | 方法 | 认证 | 说明 |
|------|------|------|------|
| `/api/v1/beta/auth` | GET | 公开 | 客户端验证QQ号+设备码 |
| `/api/v1/beta/qq` | GET | Token | 后台获取授权QQ列表 |
| `/api/v1/beta/qq` | POST | Token | 后台添加授权QQ |
| `/api/v1/beta/qq` | DELETE | Token | 后台删除授权QQ |
| `/api/v1/beta/bind` | GET | Token | 后台获取设备绑定列表 |
| `/api/v1/beta/bind` | POST | Token | 后台解绑设备 |

### 4.2 客户端验证接口（核心）

**请求**：
```
GET /api/v1/beta/auth?client_id=xxx&qq=123456&platform=windows&version=2.1.0
```

**响应（成功）**：
```json
{
  "code": 0,
  "data": {
    "authorized": true,
    "qq_number": "123456",
    "is_new_bind": false
  },
  "message": "success"
}
```

**响应（失败）**：
```json
{
  "code": 0,
  "data": {
    "authorized": false,
    "reason": "qq_not_authorized",
    "cooldown_remaining": 0
  },
  "message": "success"
}
```

`reason` 枚举值：
- `qq_not_authorized` — QQ号不在授权名单
- `qq_already_bound` — QQ号已绑定其他设备
- `cooldown` — 冷却中（附带 `cooldown_remaining` 秒数）

### 4.3 验证逻辑伪代码

```php
function handleBetaAuth($clientId, $qq, $platform, $version, $ip) {
    // 1. 防爆破检查
    $cooldown = checkCooldown($clientId, $ip);
    if ($cooldown > 0) {
        return fail('cooldown', $cooldown);
    }

    // 2. 检查该设备码是否已绑定（已绑定直接放行）
    $bind = findBind($clientId);
    if ($bind) {
        // 已绑定，更新活跃时间
        updateLastActive($clientId);
        return success(['authorized' => true, 'is_new_bind' => false]);
    }

    // 3. 未绑定 → 验证QQ号
    // 3a. QQ号是否在授权名单
    $auth = findQqAuth($qq);
    if (!$auth || !$auth['is_active']) {
        logAuth($clientId, $qq, $ip, 0, 'qq_not_authorized');
        return fail('qq_not_authorized');
    }

    // 3b. QQ号是否已绑定其他设备
    $existBind = findBindByQq($qq);
    if ($existBind && $existBind['client_id'] !== $clientId) {
        logAuth($clientId, $qq, $ip, 0, 'qq_already_bound');
        return fail('qq_already_bound');
    }

    // 4. 绑定
    insertBind($qq, $clientId, $platform, $version, $ip);
    logAuth($clientId, $qq, $ip, 1, '');
    return success(['authorized' => true, 'is_new_bind' => true]);
}
```

## 五、客户端实现

### 5.1 内测包标识

在 `app_config.py` 中添加：

```python

IS_BETA_BUILD = False
```

打包内测包时，将 `IS_BETA_BUILD` 改为 `True` 再打包。

### 5.2 启动时验证流程

在 `ui.py` 主窗口 `__init__` 末尾添加：

```python
if app_config.IS_BETA_BUILD:
    QTimer.singleShot(500, self._check_beta_auth)

def _check_beta_auth(self):
    """内测包启动时验证QQ号授权"""
    client_id = self.cloud_service.client_id
    # 先查本地是否已记录绑定
    bind_file = os.path.join(app_dir, "beta_bind.json")
    if os.path.exists(bind_file):
        # 本地有记录，静默验证
        with open(bind_file, 'r') as f:
            local = json.load(f)
        result = self.cloud_service.check_beta_auth(local.get('qq', ''), client_id)
        if result.get('authorized'):
            return  # 已绑定，直接进入

    # 未绑定 → 弹出QQ号输入窗口
    dlg = BetaAuthDialog(self, client_id)
    if dlg.exec_() == QDialog.Accepted:
        # 验证成功，保存本地记录
        with open(bind_file, 'w') as f:
            json.dump({'qq': dlg.qq_number, 'client_id': client_id}, f)
    else:
        # 验证失败或关闭，退出程序
        QApplication.quit()
        os._exit(0)
```

### 5.4 cloud_service.py 新增方法

```python
def check_beta_auth(self, qq_number, client_id):
    """验证内测QQ号授权"""
    try:
        resp = self.session.get(
            f"{API_BASE}/beta/auth",
            params={
                "client_id": client_id,
                "qq": qq_number,
                "platform": self.platform,
                "version": self.current_version,
            },
            timeout=10,
        )
        data = resp.json()
        if data.get("code") == 0:
            return data.get("data", {})
    except Exception:
        pass
    return {"authorized": False, "reason": "network_error"}
```

### 7.4 内测包分发流程

1. 云端后台添加测试员的QQ号到授权名单
2. 修改 `IS_BETA_BUILD = True`，打包内测安装包
3. 在版本管理中上传内测包，通道选 `beta`
4. 将安装包发给测试员
5. 测试员安装后首次打开 → 输入QQ号 → 绑定设备 → 进入程序
6. 后续打开自动验证，无需再输入QQ号

## 八、安全注意事项

1. **设备码不可伪造**：`client_id` 基于 UUID 生成存于本地文件，删除文件会生成新设备码（需重新输入QQ号）
2. **QQ号一次性绑定**：绑定后其他设备无法使用同一QQ号
3. **防爆破**：通过 `beta_auth_log` 表记录失败日志，触发冷却
4. **后台解绑**：管理员可在后台解绑设备（如测试员换电脑），解绑后该设备码需重新输入QQ号
5. **HTTPS**：所有请求走 HTTPS，防止中间人攻击
6. **本地缓存**：客户端保存 `beta_bind.json` 记录绑定状态，减少云端请求；但每次启动仍会静默验证（防止离线篡改）
